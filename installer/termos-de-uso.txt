CLÁUSULA 1 — OBJETO E DESCRIÇÃO DO SOFTWARE
________________________________________________________________________________

1.1  O SoftPrint é um aplicativo de gerenciamento local de impressão,
     desenvolvido pela Softnew, que permite a organizações e usuários
     individuais receber, organizar, priorizar e encaminhar pedidos de
     impressão a impressoras físicas instaladas no sistema operacional
     Windows (edições Moderna e Legacy) ou Linux (via CUPS).

1.2  O Software opera inteiramente no dispositivo local do Usuário. Por
     padrão, a interface de programação de aplicativos (API) e o painel de
     gerenciamento escutam exclusivamente no endereço de loopback
     127.0.0.1, sem exposição à rede externa, salvo configuração explícita
     realizada pelo próprio Usuário.

1.3  São características funcionais do Software, sujeitas a variação
     conforme a versão instalada:
     (a) recepção e enfileiramento de pedidos de impressão via API REST
         local;
     (b) suporte a arquivos nos formatos PDF, imagens (JPEG, PNG, BMP,
         TIFF, GIF) e comandos ESC/POS;
     (c) monitoramento de pastas de entrada (inbox) para impressão
         automática;
     (d) integração via webhook configurável pelo Usuário;
     (e) painel de gerenciamento acessível por navegador web;
     (f) fila de impressão com prioridade, reordenação e reimpressão;
     (g) descoberta de impressoras em rede local;
     (h) verificação e aplicação automática de atualizações de versão.

1.4  O SoftPrint é disponibilizado em diferentes edições:
     (a) Edição Moderna — compatível com Windows 10 ou superior (x64 e
         x86), construída sobre .NET 10.0;
     (b) Edição Legacy — compatível com Windows 7 SP1 ou superior,
         construída sobre .NET Core 3.1 (ver Cláusula 10);
     (c) Edição Linux — compatível com distribuições Linux x86-64 com
         CUPS instalado.
